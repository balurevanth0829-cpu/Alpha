# 🚀 Python Projects Collection

Welcome to my Python Projects Repository! This repository contains beginner-friendly projects developed to improve my programming skills and gain practical experience in software development.

## 📂 Projects

### 1. 🌐 Language Translation Tool

A web-based application that translates text between different languages using Python and Streamlit.

**Features**
- Translate text between supported languages.
- Select source and target languages.
- Download translated text.
- Convert text to speech.
- Simple and user-friendly interface.

**Technologies Used**
- Python
- Streamlit
- Requests
- gTTS
- MyMemory Translation API

**How to Run**

```bash
cd Language-Translation-Tool
pip install -r requirements.txt
streamlit run app.py
```
